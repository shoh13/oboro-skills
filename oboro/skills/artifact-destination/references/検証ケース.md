# 検証ケース

| ケース | 期待結果 |
| --- | --- |
| ユーザーがNotionページを指定 | 指定ページ、確認不要 |
| 候補DBが複数で優先差なし | 書き込み停止、確認必要 |
| 個人Repoに既存の文書配置規則あり | 既存規則に合うパス、確認不要 |
| 会社Repoの組織ポリシーが保存先を指定 | 組織指定先、確認不要 |
| ユーザー指定と環境既定が異なる | ユーザー指定を優先 |
| 指定先へ書き込み権限がない | 代替を推測せず確認必要 |
| 正本がなく、oboro の設定ファイルに `destination.adr_dir` がある、Repo に閉じない ADR | そのディレクトリ、確認不要 |
| `destination.adr_dir` のディレクトリがない | 確定せず`不足`。ディレクトリを作らない |
| ルールのページの保存先の規則が当てはまり、`destination.adr_dir` もある | ルールのページの保存先。設定ファイルは読まない |
| 指示ファイルが指す正本を読めず、`destination.adr_dir` がある | 設定で補わず`不足` |
