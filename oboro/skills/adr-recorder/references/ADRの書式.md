# ADRの書式

```markdown
## Title

- Author: <作成者>
- Deciders: <決定者>
- Date: YYYY-MM-DD
- Supersedes: <置き換えるADR。なければ N/A>

## Status

- [ ] Draft
- [ ] Accepted
- [ ] Rejected
- [ ] Deprecated
- [ ] Superseded

## Decision
<採用する判断>

## Context
<背景、課題、制約>

## Alternatives
<検討した選択肢>

## Consideration
<比較と採用・却下理由>

## Consequences
<メリット、デメリット、トレードオフ>

## References
<関連資料>
```

Statusは1項目だけを有効にする。完成したADRへ説明用注釈を残さない。
