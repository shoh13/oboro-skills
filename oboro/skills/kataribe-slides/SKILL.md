# kataribe:slides

スキルを起動するたび、プロジェクトのファイルを書く前に `uv run --project <プラグインのルート> kataribe assets` を実行して、立ち絵素材の状態と、最後の行の出力先の既定を確かめる。話者を聞くときの候補の絞り方、話者の口調、実行環境（書き込めないスキルのディレクトリでの実行を含む）は、隣の `../kataribe/SKILL.md` の「最初に行うこと」「話者の口調」「実行環境」に従う。

地の文（解説）を本文に出し、立ち絵のキャラクターが表情を変えながら、バラエティ番組のテロップのような大きな文字でコメントしていく PowerPoint（`out/slides.pptx`、16:9 = 13.33x7.5 インチ）を作る。音声は合成しない（TTS も Docker も不要）。台本は解説動画（`oboro:kataribe`）と同じ `script.json` で、話者はずんだもん・四国めたん・春日部つむぎ・雨晴はう・あんこもんから2人まで。

## プロジェクトの形

```javascript
<project>/script.json    台本（必須）
<project>/scenes.html    図（任意。シーンごとの <section data-scene="シーンID">）
<project>/readings.json  読みの辞書（任意。スライドでは使わない）
```

`script.json`:

```json
{
  "title": "スライドの題名",
  "description": "表紙に出す説明（任意）",
  "sources": [{"title": "出典のタイトル", "url": "https://example.com/"}],
  "chapters": [
    {"id": "c1", "title": "章のタイトル", "scenes": [
      {"id": "s1", "title": "スライドの見出し", "lines": [
        {"text": "地の文。解説はここに書く。**強調**もできる。"},
        {"speaker": "ずんだもん", "expression": "surprised", "text": "コメントはテロップで大きく出るのだ"}
      ]}
    ]}
  ]
}
```

- `speaker` のない行が地の文（解説）。地の文に `expression` を付けるとエラー。
- `speaker` のある行がコメント。`speaker` は `ずんだもん`、`四国めたん`、`春日部つむぎ`、`雨晴はう`、`あんこもん` のどれかで、1本で2人まで（3人目が出た行で失敗する）。`expression`（任意。省略すると `normal`）で表情を変える。
- 地の文とコメントの `**…**` は強調（太字・色つき）になる。
- 見出しはシーンの `title`（任意。書くなら空でない文字列）で、その上に章の題名を小さく出す。`title` がなければ、章の題名を見出しにする。
- 地の文のある台本は、動画の `build`・`lint` では使えない（`speaker` のない行がエラーになる）。

## プロジェクトの場所と出力先

- 台本から作るときは、プロジェクト（`script.json`、図を使うなら `scenes.html`）を置くディレクトリを、ユーザーが指定していなければ、ファイルを書く前にユーザーに聞く。出力先のディレクトリも、ユーザーが指定しておらず、`assets` の最後の行が `出力先の既定: <プロジェクト>/out`（設定がない）なら、同じときに聞く。決めずに作り始めない（プラグインのディレクトリの中に勝手に作らない）。
- 出力先は `slides` の `--out <ディレクトリ>` で指定する（ないディレクトリは作る）。付けなければ、oboro の設定ファイル（setup-oboro が書く）の `kataribe.output_dir` の下の `<プロジェクトのディレクトリ名>-<パスから作る8文字>`（8 文字はプロジェクトの絶対パスから作るので、名前の同じ別のプロジェクトは別の出力先になる）、設定がなければ `<project>/out`。以下の `out/` は、この出力先を指す。設定で決まるときの実際のパス（8 文字を含む）は、`assets` の最後の行ではわからない（雛形だけを出す）。各コマンドが標準エラーに出す `出力先: …` の行で知る。
- `assets` の最後の行に `kataribe.output_dir` が出ていて、ユーザーが出力先を指定していなければ、出力先を聞かず、`--out` を付けない。
- 作り終えたら、`slides.pptx` のパスをユーザーに伝える（設定で決めたときは、`slides` が標準エラーに出す `出力先: …` の下）。

## 作る

プラグインのルートは、この `SKILL.md` のあるディレクトリから上へたどって、最初に `pyproject.toml` が見つかるディレクトリ（このスキルでは同じディレクトリ）。カレントディレクトリに関係なく、次のように実行する。

```bash
uv run --project <プラグインのルート> kataribe lint <project> --slides
uv run --project <プラグインのルート> kataribe slides <project> [--out <出力先>]
```

- 出力は、出力先と同じ場所の一時ディレクトリに作ってから `out/slides.pptx` だけを置き換える（`out/video.html` など、ほかのファイルには触らない）。失敗したときは、前回の `out/slides.pptx` はそのまま残る。
- `scenes.html` に図があるときだけブラウザを使う（Google Chrome、なければ Playwright Chromium）。
- 出力は Google スライドで開く前提で作る（下の「文字とフォント」）。

## 検査する（lint --slides）

`slides` も、作る前に同じ検査をする。素材は取得せず、立ち絵の定義だけで検査する。

- 失敗（終了コード1）: 動画の `lint` と同じ台本の誤り（`title` がない、`speaker` が許可リストにない、3人目の話者、`expression` が空でない文字列でない、その話者の立ち絵の定義にない表情、空の `text`、章が1つもない、行が1つもない章、シーン ID・章 ID の重複や空、`description`・`sources` の構造の誤りなど）、地の文に `expression`、シーンの `title` が空・文字列でない、`readings.json` があるときの形式の誤り、`scenes.html` の同じ `data-scene` の重複、`data-at`・`data-out`・`data-focus` の誤り、`scenes.html` の画像のファイルがない。
- 失敗にしないもの: `readings.json` と `scenes.html` がない、台本のシーンに対応する `section` がない（そのシーンのスライドは図なし）。
- 警告（続行）: 同じ解説へのコメントが多く（長く）、18pt にしてもテロップが帯に収まらない（かたまりの最初と最後の行を示す）、地の文が1枚に収まらない、図のあるスライドの地の文が図の横に収まらない（いずれも「文字に合わせた大きさ」の見積もりで判定）、`scenes.html` の余った `section`。

## スライドの構成

- 表紙（題名、`description`、2人の立ち絵）、台本の1行ごとに1枚、最後にクレジット。
- アニメーションは使わず、行ごとにスライドを分ける（同じシーンのスライドは見出しと地の文が積み上がるので、めくると1枚が段階的に進むように見える）。
- 発表者ノートに、そのスライドで増えた行（`話者: 文`、地の文は `地の文: 文`。強調の記号は除く）を入れる。
- クレジットのスライドに、立ち絵のクレジット（定義の `source.credit`）と非商用の注意、立ち絵の規約（定義の `source.terms`）、出典（`sources`）をリンクつきで出す。声は使わないので、声のクレジットは出さない。

## 画面

- 見た目の白い枠（解説の枠。0.23〜13.10 × 0.20〜5.37 インチ）と、見出し・地の文・図を収める範囲（解説の領域。同じ幅で、下端は立ち絵の頭の4.60インチ）を分ける。地の文と図は解説の領域からはみ出さない（下端の0.15インチ上まで）。立ち絵とテロップは、解説の枠の下端に重なる。
- 図のないスライド: 解説の領域の左右いっぱい（画面の端から0.6インチずつ内側）の段に、そのシーンの今の行までの地の文を上から積む。今の地の文はオレンジの番号の印（シーンの中の地の文の番号）を付けて大きく濃く、それより前は灰色の印で小さく薄く出す。入りきらなければ、古いものから省く。
- 図のあるスライド: 解説の領域の左に図（16:9。高さは解説の領域に収まる2.8インチ、幅は約5インチ）、右に今の地の文だけを出す。

## 図（scenes.html）

- `scenes.html` にシーンの `<section data-scene="…">` があれば、そのシーンのスライドに図を出す。図は、`section` を動画と同じ 1280x720 の箱（余白24px）に置き、Chrome でその行の状態を撮った画像（背景は透明）。動画用に書いた `scenes.html` が、そのままスライドの図になる。
- 行番号はシーンの中の0始まりで、地の文もコメントも1行と数える。`data-at="n"`（n 行目から表示）、`data-out="n"`（n 行目で消える）、`data-focus="n,m"`（その行で強調し、同じ親の中のほかの `data-focus` の要素を薄くする）の規則は動画と同じ（詳しくは 隣の `../kataribe/SKILL.md` の「行単位の出現」）。
- 祖先の要素（`section` の中で `data-at`・`data-out` を持つもの）が消えている間は、子も消える。消えている要素も場所は残るので、同じ場所で図を入れ替えるときは、パネルを1つのグリッドのセルに重ねて `data-out` と `data-at` で切り替える（書き方は 隣の `../kataribe/SKILL.md` の「行単位の出現」）。
- 図の部品の CSS（クラス名は `kt-` で始まる）も、動画と同じく図に埋め込むので、部品で書いた図はスライドでも同じ見た目になる（部品の一覧は 隣の `../kataribe/SKILL.md` の「図の部品（kit）」）。
- CSS の変数は、`--p` がその行が終わった時点の値、`--lp` が1。撮影ではアニメーションを止める（`transition` と、回数の決まった `animation` は完了状態で撮る）。
- `<img src="…">`（`<source>`、SVG の `<image href>` も）の相対パスは、プロジェクトのディレクトリからのパスで、data URI にして埋め込む。`http(s)`・`data:`・`/` や `//` で始まる参照は、そのまま残す。

## 立ち絵

- 立ち絵の素材の取得・キャッシュ・定義は動画と同じ（詳しくは 隣の `../kataribe/SKILL.md` の「立ち絵の素材」）。素材の置き場所は、環境変数 `KATARIBE_CHAR_SOURCES`、oboro の設定ファイル（setup-oboro が書く）の `kataribe.char_sources`、既定の `~/Documents/kataribe-assets` の順に決める（`kataribe assets` の `素材なし` の行に、決まった置き場所が出る）。ずんだもん・四国めたんは、置き場所に zip がなければ配布元から取得して、キャッシュ（既定は `~/.cache/kataribe/characters`）と置き場所に保存する。春日部つむぎ・雨晴はう・あんこもんは使う人が落とした zip を置き場所に置く。zip がなければ、配布元のページ、zip の名前、置き場所を示して失敗する。`lint --slides` も、使う話者の素材がなければ同じ手順を示して警告する（失敗にはしない）。
- 表情は全員9種（`normal`、`smile`、`surprised`、`troubled`、`jito`、`panic`、`think`、`angry`、`cry`）。立ち位置は定義の `side`（四国めたん・春日部つむぎ・雨晴はうは左、ずんだもん・あんこもんは右。2人が同じ側なら、後から出た人を反対側に置く）。
- 立ち絵は左右の下に置く（全身の高さ4インチのうち、上端4.6インチから下端まで。口は閉じ、目は開けた1枚の画像。中央を向くように左右を反転する）。
- 表情は、話している人はその行の表情、ほかの人は最後に話した行の表情（まだ話していなければ `normal`）。地の文の行は飛ばす。
- 素材と書き出した画像は、git にも共有用の zip にも入れない（作者が素材の再配布を許していない）。利用は非商用に限る。

## テロップ（コメント）

- ひとかたまりの解説（シーンの先頭か地の文から、次の地の文の前まで）のコメントは、消さずに上から順に積み、次の地の文で消す。
- 配置は、かたまりの全部のコメントで先に決める（最後のコメントの下端を画面の下から0.2インチにそろえ、その上へ0.08インチの間をあけて前のコメントを置く）ので、めくっても位置は動かず、後のコメントの場所は空けておく。
- 帯（解説の枠の下、5.5インチから下）に入らなければ、そのかたまりだけ文字を28ptから2ptずつ小さくする（下限18pt）。
- テロップの枠（幅8インチ）はスライドの中央にそろえ、文字は左に立つ人は左詰め、右に立つ人は右詰めにする。
- 文字は太字で、色は話者の定義の `color`（白とのコントラスト比が4.5に届かない淡い色は、届くまで暗くする）。`**…**` は地の文と同じ強調の色。
- 縁取りは付けない（Google スライドは文字の縁取りを表示しないため。解説の枠の下の無地の地に置いて読ませる）。

## 文字とフォント

- 文字に合わせた大きさ: 行の高さは文字の大きさの1.5倍に固定し、文字の幅は全角を1字、半角を0.6字として、余裕を10%取って折り返しを見積もる。地の文の高さは、この行数に半行の予備を足して決める。テロップは下端をそろえるので、見積もりが外れても上の隙間へ伸びる。
- フォントは Noto Sans JP（Google スライドで使える。Google スライドは Google Fonts にない Hiragino Sans や Yu Gothic を Arial などに置き換えるため）。`KATARIBE_SLIDES_FONT` で差し替えられる。
- 図形には名前を付ける（`解説の枠`、`見出し`、`地の文 <番号>`、`番号 <番号>`、`図`、`テロップ <話者>（<行ID>）`、`立ち絵 <話者>（<表情>）`、`表紙`、`クレジット`）。

## 現在できないこと

- 音声・アニメーション（行ごとのスライドの切り替えで進める）。
